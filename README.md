# vendly-site

Páginas públicas de [Vendly](https://drgerssonsr.github.io/vendly-site/), la extensión de Chrome para vender en
lives. Se publican con GitHub Pages desde la rama `main`.

- `privacy/`: política de privacidad (español, inglés y portugués).

La fuente de verdad está en el repo privado de la extensión (`site/`). Para actualizar esta página, se copia de
ahí y se hace commit en este repo.
